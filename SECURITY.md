# Security

Please report a security problem privately, not in a public issue:
open **Security > Report a vulnerability** on this repository
(GitHub private vulnerability reporting).

Useful to include: the command you ran, what happened, and your macOS version.
Leave out folder names and file names you do not want to share; sizes and the
tool's own messages are usually enough.

What counts here: the tool removing or moving something a dry run did not
list, removing anything outside the home folder, reading file contents,
sending anything over the network, or showing names from inside a folder
marked private.
